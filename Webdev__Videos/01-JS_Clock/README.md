JavaScript Clock

This project is about creating a functional clock using HTML, CSS, and JS.

The HTML served in providing the overall structure of the page, creating the different parts of it.
The CSS provides the styling of the different HTML elements. Its the CSS that gave the clock its border, the page it's background color, as well as the the arrows their designs.

Things I learned:
CSS:
I learned two new CSS attributes, transform-origin and transform: rotate.
The first one, transform-origin sets the point of anchor around which an element's transformations, such as rotation and skaling, occur. In this program, it was used to set the center of the clock as the point of rotation for the two arrows.
The second CSS element, transform: rotate, spins an element around a fixed point. In this program, the element is used to make the two arrows spin around the center.

JavaScript:
Another thing I learned is the JS funtion setInterval, used in the line setInterval(setDate, 1000). The function setInterval() is used to run another funtion or piece code several times after a specific amount of time. In this program, the function is used to run setDate() function repeatedly every 1 second.
